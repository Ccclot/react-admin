## 环境准备

### 服务器要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 2核 | 4核 |
| 内存 | 4GB | 8GB |
| 磁盘 | 50GB | 100GB |
| 系统 | CentOS 7+ / Ubuntu 18+ | CentOS 7.9 |

### 需要安装的软件

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 1.8+ | Java 运行环境 |
| MySQL | 5.7+ / 8.0+ | 数据库 |
| Nginx | 1.18+ | Web 服务器/反向代理 |
| Node.js | 18+ | CopilotKit 后端运行环境 |
| PM2 | 最新 | Node.js 进程管理 |

### 安装命令（CentOS）

```bash
# 1. 安装 JDK 1.8
yum install -y java-1.8.0-openjdk java-1.8.0-openjdk-devel
java -version

# 2. 安装 MySQL 8.0
yum install -y mysql-server
systemctl start mysqld
systemctl enable mysqld

# 3. 安装 Nginx
yum install -y nginx
systemctl start nginx
systemctl enable nginx

# 4. 安装 Node.js 18
curl -fsSL https://rpm.nodesource.com/setup_18.x | sudo bash -
yum install -y nodejs
node -v

# 5. 安装 PM2
npm install -g pm2
pm2 -v
```

## Java 后端部署

### 1. 修改配置文件

**文件：** `ruoyi-admin/src/main/resources/application.yml`

```yaml
# 生产环境配置
server:
  port: 8080

spring:
  datasource:
    druid:
      driver-class-name: com.mysql.cj.jdbc.Driver
      url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%8
      username: root
      password: YOUR_MYSQL_PASSWORD  # 修改为实际密码

# 日志配置
logging:
  level:
    com.ruoyi: info
  file:
    name: /var/log/ruoyi/ruoyi.log
```

### 2. 打包项目

在开发机器上执行：

```bash
# 进入项目根目录
cd ruoyi-react

# Maven 打包（跳过测试）
mvn clean package -Dmaven.test.skip=true

# 打包完成后，JAR 文件位于：
# ruoyi-admin/target/ruoyi-admin.jar
```

### 3. 上传到服务器

```bash
# 创建目录
mkdir -p /opt/ruoyi

# 上传 JAR 文件（使用 scp 或其他工具）
scp ruoyi-admin/target/ruoyi-admin.jar user@server:/opt/ruoyi/

# 上传配置文件（可选，如果需要修改）
scp ruoyi-admin/src/main/resources/application.yml user@server:/opt/ruoyi/
```

### 4. 启动 Java 后端

**方式一：直接启动**

```bash
cd /opt/ruoyi
java -jar ruoyi-admin.jar
```

**方式二：使用 systemd 服务（推荐）**

创建服务文件：`/etc/systemd/system/ruoyi.service`

```ini
[Unit]
Description=RuoYi Admin Service
After=network.target mysql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/ruoyi
ExecStart=/usr/bin/java -jar /opt/ruoyi/ruoyi-admin.jar
ExecStop=/bin/kill -15 $MAINPID
Restart=on-failure
RestartSec=10s

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
# 重载 systemd 配置
systemctl daemon-reload

# 启动服务
systemctl start ruoyi

# 设置开机自启
systemctl enable ruoyi

# 查看状态
systemctl status ruoyi

# 查看日志
journalctl -u ruoyi -f
```

## React 前端部署

### 1. 修改 API 地址

**文件：** `react-ui/config/config.ts` 或环境变量

```typescript
// 生产环境 API 地址
export default {
  define: {
    API_URL: 'https://your-domain.com/api',  // 或 http://your-ip:8080
  },
};
```

**修改 CopilotKit 地址：** `react-ui/src/components/CopilotKitProvider/index.tsx`

```tsx
<CopilotKit runtimeUrl="https://your-domain.com/copilotkit">
  {/* 或使用相对路径（通过 Nginx 代理） */}
  <CopilotKit runtimeUrl="/copilotkit">
```

### 2. 构建前端

在开发机器上执行：

```bash
cd react-ui

# 安装依赖（如果未安装）
pnpm install

# 构建生产版本
pnpm build

# 构建完成后，静态文件位于：
# react-ui/dist/
```

### 3. 上传到服务器

```bash
# 创建目录
mkdir -p /usr/share/nginx/html/ruoyi

# 上传构建产物
scp -r react-ui/dist/* user@server:/usr/share/nginx/html/ruoyi/
```

## CopilotKit 后端部署

### 1. 上传 CopilotKit 后端

```bash
# 创建目录
mkdir -p /opt/copilotkit

# 上传整个目录
scp -r copilotkit-backend/* user@server:/opt/copilotkit/
```

### 2. 安装依赖

```bash
cd /opt/copilotkit
npm install
```

### 3. 使用 PM2 启动

```bash
cd /opt/copilotkit

# 启动服务
pm2 start server.js --name copilotkit

# 查看状态
pm2 status

# 查看日志
pm2 logs copilotkit

# 设置开机自启
pm2 startup
pm2 save
```

### 4. PM2 常用命令

```bash
# 重启
pm2 restart copilotkit

# 停止
pm2 stop copilotkit

# 删除
pm2 delete copilotkit

# 监控
pm2 monit
```

## Nginx 配置

### 1. 创建配置文件

**文件：** `/etc/nginx/conf.d/ruoyi.conf`

```nginx
upstream java_backend {
    server 127.0.0.1:8080;
    keepalive 32;
}

upstream copilotkit_backend {
    server 127.0.0.1:4000;
    keepalive 32;
}

server {
    listen 80;
    server_name your-domain.com;  # 修改为你的域名或 IP

    # React 前端静态文件
    location / {
        root /usr/share/nginx/html/ruoyi;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # Java 后端 API
    location /api/ {
        proxy_pass http://java_backend/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 30s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # CopilotKit 后端
    location /copilotkit/ {
        proxy_pass http://copilotkit_backend/copilotkit/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支持（如果需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 120s;
        proxy_read_timeout 120s;
    }

    # 日志
    access_log /var/log/nginx/ruoyi_access.log;
    error_log /var/log/nginx/ruoyi_error.log;
}
```

### 2. 测试并重载配置

```bash
# 测试配置
nginx -t

# 重载配置
nginx -s reload
```

### 3. HTTPS 配置（可选）

如果需要 HTTPS，使用 Let's Encrypt：

```bash
# 安装 certbot
yum install -y certbot python3-certbot-nginx

# 获取证书
certbot --nginx -d your-domain.com

# 自动续期
certbot renew --dry-run
```

HTTPS 配置示例：

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # 其他配置同上...
}

# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

## MySQL 数据库

### 1. 创建数据库

```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE ry_vue DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

-- 创建用户（可选）
CREATE USER 'ruoyi'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON ry_vue.* TO 'ruoyi'@'localhost';
FLUSH PRIVILEGES;
```

### 2. 导入初始数据

```bash
# 上传 SQL 文件
scp sql/*.sql user@server:/tmp/

# 导入数据
mysql -u root -p ry_vue < /tmp/ry_vue.sql
```

### 3. 数据库安全配置

```bash
# 运行安全配置脚本
mysql_secure_installation

# 设置项：
# - 设置 root 密码
# - 删除匿名用户
# - 禁止 root 远程登录
# - 删除测试数据库
# - 重载权限表
```

## 完整部署流程

### 步骤一：准备服务器

```bash
# 1. 安装所有依赖软件
yum install -y java-1.8.0-openjdk nginx mysql-server
curl -fsSL https://rpm.nodesource.com/setup_18.x | bash -
yum install -y nodejs
npm install -g pm2

# 2. 启动基础服务
systemctl start mysqld
systemctl enable mysqld
systemctl start nginx
systemctl enable nginx

# 3. 创建目录
mkdir -p /opt/ruoyi /opt/copilotkit /usr/share/nginx/html/ruoyi /var/log/ruoyi
```

### 步骤二：配置数据库

```bash
# 1. 创建数据库和导入数据
mysql -u root -p
CREATE DATABASE ry_vue DEFAULT CHARACTER SET utf8mb4;
exit

mysql -u root -p ry_vue < /path/to/ry_vue.sql
```

### 步骤三：部署 Java 后端

```bash
# 1. 上传 JAR 文件到 /opt/ruoyi/

# 2. 创建 systemd 服务
vi /etc/systemd/system/ruoyi.service
# [内容见上文]

# 3. 启动服务
systemctl daemon-reload
systemctl start ruoyi
systemctl enable ruoyi
```

### 步骤四：部署 CopilotKit 后端

```bash
# 1. 上传 copilotkit-backend 到 /opt/copilotkit/

# 2. 安装依赖
cd /opt/copilotkit && npm install

# 3. 使用 PM2 启动
pm2 start server.js --name copilotkit
pm2 startup && pm2 save
```

### 步骤五：部署 React 前端

```bash
# 1. 上传 dist/ 到 /usr/share/nginx/html/ruoyi/

# 2. 配置 Nginx
vi /etc/nginx/conf.d/ruoyi.conf
# [内容见上文]

# 3. 重载 Nginx
nginx -t && nginx -s reload
```

### 步骤六：验证部署

```bash
# 检查所有服务状态
systemctl status ruoyi      # Java 后端
systemctl status nginx      # Nginx
pm2 status                  # CopilotKit
systemctl status mysqld     # MySQL

# 检查端口
netstat -tlnp | grep -E '8080|4000|3306|80|443'

# 检查日志
journalctl -u ruoyi -f
pm2 logs copilotkit
tail -f /var/log/nginx/ruoyi_error.log
```

## 常见问题

### 1. Java 后端启动失败

**检查项：**

```bash
# 查看 Java 版本
java -version

# 查看日志
journalctl -u ruoyi -n 100

# 手动启动测试
cd /opt/ruoyi && java -jar ruoyi-admin.jar
```

**常见原因：**
- MySQL 连接失败：检查数据库地址、用户名、密码
- 端口被占用：`netstat -tlnp | grep 8080`
- 内存不足：调整 JVM 参数 `-Xmx512m`

### 2. Nginx 502 Bad Gateway

**检查项：**

```bash
# 检查后端是否运行
curl http://127.0.0.1:8080/api/getInfo
curl http://127.0.0.1:4000/health

# 查看 Nginx 错误日志
tail -f /var/log/nginx/ruoyi_error.log
```

### 3. CopilotKit 连接失败

**检查项：**

```bash
# 检查服务状态
pm2 logs copilotkit

# 测试端点
curl http://127.0.0.1:4000/health

# 检查 API Key 是否正确
vi /opt/copilotkit/server.js
```

### 4. 前端页面空白

**检查项：**

```bash
# 检查静态文件
ls -la /usr/share/nginx/html/ruoyi/

# 检查浏览器控制台错误
# F12 -> Console

# 检查 API 地址配置
# react-ui/src/components/CopilotKitProvider/index.tsx
```

### 5. 内存不足

**解决方案：**

```bash
# 调整 Java JVM 参数
vi /etc/systemd/system/ruoyi.service
# ExecStart=/usr/bin/java -Xmx512m -jar /opt/ruoyi/ruoyi-admin.jar

# 重启服务
systemctl daemon-reload
systemctl restart ruoyi
```

## 备份策略

### 数据库备份

```bash
# 创建备份脚本
vi /opt/scripts/backup_mysql.sh

#!/bin/bash
BACKUP_DIR="/opt/backups/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

mysqldump -u root -p'YOUR_PASSWORD' ry_vue > $BACKUP_DIR/ry_vue_$DATE.sql

# 删除 7 天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete

# 添加到定时任务
crontab -e
# 每天凌晨 2 点备份
0 2 * * * /opt/scripts/backup_mysql.sh
```
